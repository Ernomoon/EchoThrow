# Как залить EchoThrow на GitHub и получить установщик

Всё собирается на серверах GitHub автоматически: тебе не нужны ни Visual Studio, ни Xcode.
На выходе получаешь **EchoThrow-Setup-Windows.exe** и **EchoThrow-macOS.pkg**.

## 1. Аккаунт и репозиторий
1. Зарегистрируйся на https://github.com (если ещё нет аккаунта).
2. Нажми **+ → New repository**.
3. Имя: `EchoThrow`. Поставь **Public** (публичный репозиторий даёт бесплатные минуты сборки, а лицензия JUCE/AGPL это и подразумевает).
4. **Ничего** не отмечай галочками (никаких README, .gitignore, license) — они уже есть в проекте. Нажми **Create repository**.

## 2. Загрузка файлов (выбери один способ)

### Способ A. GitHub Desktop (проще всего)
1. Скачай https://desktop.github.com и войди в аккаунт.
2. **File → Add local repository…** → выбери папку `EchoThrow` (где лежит `CMakeLists.txt`). Если спросит про создание репозитория — согласись (**create a repository**).
3. Внизу слева напиши сообщение, например `first version`, и нажми **Commit to main**.
4. Нажми **Publish repository** (или **Push origin**). Галочку «Keep this code private» **сними**.

### Способ B. Командная строка (нужен установленный Git)
В папке проекта:
```bash
git init -b main
git add .
git commit -m "first version"
git remote add origin https://github.com/ТВОЙ_НИК/EchoThrow.git
git push -u origin main
```
GitHub попросит войти (откроется окно браузера).

> Важно: папка `.github/workflows` (с точкой в начале) **обязана** попасть в репозиторий, иначе сборка не запустится. Через сайт перетаскивание иногда её пропускает — поэтому лучше A или B.

## 3. Проверь, что сборка пошла
1. Открой репозиторий → вкладка **Actions**.
2. Если GitHub просит включить workflows — нажми **I understand my workflows, go ahead and enable them**.
3. Появится запуск **Build installers**: два задания, `windows` и `macos`. Первая сборка идёт 10–20 минут (скачивается JUCE и компилируется всё с нуля).
4. Зелёная галочка — всё собралось. Красный крестик — открой упавшее задание, скопируй последние строки лога и пришли мне, поправлю.

Сразу после любой сборки установщики лежат в самом запуске: внизу страницы запуска раздел **Artifacts** → `EchoThrow-Windows-Installer` / `EchoThrow-macOS-Installer` (скачивается zip, внутри установщик).

## 4. Выпуск релиза с красивой ссылкой для скачивания
Чтобы установщики лежали на странице **Releases**:

**Через сайт:** репозиторий → справа **Releases → Create a new release** → в поле *Choose a tag* введи `v1.0.0` и выбери **Create new tag** → **Publish release**.

**Или командой:**
```bash
git tag v1.0.0
git push origin v1.0.0
```
Через 10–20 минут на странице **Releases** появится релиз `v1.0.0` с файлами `EchoThrow-Setup-Windows.exe` и `EchoThrow-macOS.pkg`. Ссылкой на эту страницу можно делиться с кем угодно.

Новая версия позже: поменяй изменения → commit → push → тег `v1.0.1` и т.д.

> Если релиз при создании через сайт появился пустым — это нормально: файлы дозагружаются, когда закончится сборка (смотри вкладку Actions). Если нужно перегенерировать — удали релиз и тег и создай заново.

## 5. Установка на компьютер

### Windows
1. Запусти `EchoThrow-Setup-Windows.exe`. SmartScreen может написать «Windows защитил ваш компьютер» (установщик не подписан платным сертификатом) → **Подробнее → Выполнить в любом случае**.
2. Плагин ставится в `C:\Program Files\Common Files\VST3\EchoThrow.vst3`.
3. В FL Studio: **Options → Manage plugins → Find installed plugins** (или Start scan). Если плагин не нашёлся, проверь, что в *Plugin search paths* есть `C:\Program Files\Common Files\VST3`.
4. Плагин появится в списке как **EchoThrow** (категория эффектов, **Fx**). Закинь его в слот эффекта на дорожке с вокалом.

### macOS
1. Открой `EchoThrow-macOS.pkg`. Если система говорит, что не может проверить разработчика: правой кнопкой по файлу → **Открыть** → **Открыть** (либо System Settings → Privacy & Security → **Open Anyway**).
2. Плагин ставится в `/Library/Audio/Plug-Ins/VST3`. Дальше пересканируй плагины в DAW.

## 6. Как пользоваться (коротко)
1. Поставь EchoThrow на дорожку с вокалом.
2. Нажми **REC** (кнопка загорится — плагин ждёт звук), нажми Play в FL. Запись стартует сама на первом звуке, с небольшим запасом до него, чтобы не обрезать атаку.
3. Когда слово закончилось — снова **REC**. Фрагмент автоматически обрезается по тишине.
4. Настрой делей (время/синхронизация с темпом, фидбэк, ping-pong, фильтры, дрив, модуляция, диффузия) и эквалайзер эхо справа. Результат пересчитывается сам.
5. **LISTEN** — послушать (**LOOP** — по кругу). Живой сигнал на это время заглушается (можно отключить).
6. Понравилось — возьми за кнопку **DRAG TO PLAYLIST** и перетащи прямо в плейлист FL. Файл (32-bit float WAV) лежит ещё и в `Документы/EchoThrow/Exports`.
7. Ставь клип в плейлисте **в то место, где начинается записанный фрагмент** (рядом с кнопкой показан «BAR / BEAT» — позиция записи).

## 7. Если что-то не так
| Симптом | Что делать |
|---|---|
| LISTEN молчит в FL | В окне плагина нажми шестерёнку обёртки FL (стрелка вверху справа) → сними галочку **Smart disable**. FL иногда «усыпляет» плагин при остановленном проекте. |
| Плагин не виден в списке | Проверь путь сканирования VST3 и сделай **Find installed plugins** с галочкой *Verify plugins*. |
| Actions красный | Пришли мне последние 30 строк лога упавшего задания. |
| Хочу изменить цвет/название/значения по умолчанию | Всё в `Source/` (цвета в `Source/UI/Theme.cpp`, пресеты в `Source/Presets.cpp`), после правки — commit + push. |

## 8. Лицензия
JUCE используется по AGPLv3, поэтому репозиторий публичный, а файл `LICENSE` лежит в корне. Для закрытой коммерческой версии нужна платная лицензия JUCE (https://juce.com).
